# vehicleproof.app

The VehicleProof website: home, privacy policy, terms, account deletion and support.
Plain HTML and CSS, served by GitHub Pages at https://vehicleproof.app.

| Page | File |
|---|---|
| Home | `index.html` |
| Privacy Policy | `privacy/index.html` |
| Terms of Service | `terms/index.html` |
| Delete your account | `delete-account/index.html` |
| Support | `support/index.html` |

- Edit a page, commit and push to `main`; GitHub Pages publishes it within a minute or two.
- When the privacy policy or terms change, update the "Effective" date at the top.
- `CNAME` holds the custom domain. Don't delete it.
- Preview locally: `python -m http.server 8765`, then open http://localhost:8765.
- Fonts: Inter (SIL Open Font License, see `assets/fonts/Inter-LICENSE.txt`).
